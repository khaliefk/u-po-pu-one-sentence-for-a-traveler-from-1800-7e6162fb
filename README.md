An entry for the [make.fun](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb)
"One Sentence for a Traveler from 1800" bounty: one sentence of at most
200 characters explaining the modern internet to someone arriving from
1800.

The sentence builds only from things a person from 1800 already knows —
a road, a post office, a library, a letter, a book, a candle — and lets a
single comparison carry the whole picture: a road joining every library
and post office on earth, down which a letter, a book, or a spoken word
can reach a far door before a candle burns down.

## Run it

```sh
python3 main.py
# writes /output/entry.txt
```

## Entry

> It is a road joining every library and post office on earth, so a letter, a book, or a spoken word can reach a far door before a candle burns down.

147 characters, one sentence.
